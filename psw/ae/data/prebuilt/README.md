# PCE source code
The PCE is part of Intel(R) Software Guard Extensions for Linux\* OS which is published in [confidential-computing.sgx](https://github.com/intel/confidential-computing.sgx/) GitHub repository. The libsgx_pce.signed.so in prebuilt package is built by [pce](https://github.com/intel/confidential-computing.sgx/tree/main/psw/ae/pce) with branch [sgx_2.30_reproducible](https://github.com/intel/confidential-computing.sgx/tree/sgx_2.30_reproducible) and signed by Intel.
